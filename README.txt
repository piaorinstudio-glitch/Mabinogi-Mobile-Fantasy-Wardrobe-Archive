瑪奇 Mobile 外觀圖鑑：柔綠可愛 UI 風格修正包

使用方式：
1. 解壓縮 ZIP。
2. 將 .github 和 scripts 兩個資料夾上傳到 GitHub repo 根目錄並覆蓋。
3. 到 Actions → 套用柔綠可愛 UI 風格 → Run workflow。
4. 等 workflow 綠勾，再等 pages-build-deployment 綠勾。
5. 到網站 Ctrl + F5 強制刷新。

這包主要調整：
- 整體改成柔綠、米白、圓角、可愛簡報感。
- Hero 區改成柔和白底、葉片感裝飾。
- 分類按鈕改成柔綠膠囊按鈕。
- 卡片改成柔和圖鑑卡、虛線內框。
- 搜尋框 placeholder 簡化成「搜尋中文名 / 韓文名」。
- 手機版維持分類列獨立、內容區排版較舒適。
