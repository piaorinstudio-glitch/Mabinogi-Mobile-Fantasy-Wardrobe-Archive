使用方式：
1. 解壓縮後，把 .github/ 和 scripts/ 上傳到 GitHub 倉庫根目錄覆蓋。
2. 到 GitHub 的 Actions 頁面，找到「套用指定拼貼 UI 修正」。
3. 按 Run workflow。
4. 等 workflow 綠勾後，再等 pages-build-deployment 綠勾。
5. 回網站按 Ctrl + F5。
